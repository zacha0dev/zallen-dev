# mcp-node docs

A learning resource for understanding the system. You already installed it from
the main README; these pages explain how it works and how to build on it.

Read top to bottom, or jump to what you need.

1. [Concepts](01-concepts.md) - the Model Context Protocol, what a "node" is, the model behind it.
2. [Architecture](02-architecture.md) - the components and how a request flows.
3. [Auth and identity](03-auth.md) - OAuth in, managed identity out, the RBAC gotcha.
4. [The server](04-server.md) - inside the Function App.
5. [The tools](05-tools.md) - the tool system and each built-in tool.
6. [Infrastructure](06-infrastructure.md) - the bicep, resource by resource.
7. [Cost](07-cost.md) - what it costs and what keeps it capped.
8. [Scaling](08-scaling.md) - one node to many.
9. [Extending](09-extending.md) - add your own tools and connectors.

Setup how-to: [Connecting a client](connect.md) - per-client (Claude / ChatGPT /
CLI) step-by-step.

Convention: acronyms are spelled out on first use in each page, then used short.
