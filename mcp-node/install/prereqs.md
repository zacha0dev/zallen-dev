# Prereqs

Two things. (Node, Functions tools, and openssl install themselves later.)

## 1. An Azure account

Free tier works: https://azure.microsoft.com/free

## 2. An agent CLI - pick one

This is what you paste the install line into.

Claude Code:

```
npm install -g @anthropic-ai/claude-code
```

OpenAI Codex:

```
npm install -g @openai/codex
```

GitHub Copilot:

```
npm install -g @github/copilot
```

Gemini:

```
npm install -g @google/gemini-cli
```

Then go paste the install line from the [README](../README.md).
