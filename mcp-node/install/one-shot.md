# Install

1. Paste this into an agentic CLI (Claude Code, Codex, Copilot, Gemini):

   ```
   Install mcp-node: read and follow https://github.com/zacha0dev/zallen-dev/blob/main/mcp-node/install/agent.md
   ```

2. Answer the few prompts. The agent checks your tools, logs you in, deploys,
   and prints your connect config.

Steps it follows: [agent.md](./agent.md). Prefer a plain script:
[deploy.sh](../scripts/deploy.sh) / [deploy.ps1](../scripts/deploy.ps1).
